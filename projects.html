Social Network Simulation of Misinformation Spread

  • Modeled misinformation spread with an Independent Cascade Model over a directed graph, with activation probability driven by virality of information, weights assigned to user actions, and node susceptibility
  • Assessed users’ information-evaluation behavior within the simulation using a Multi-Criteria Decision Analysis framework, based on decision accuracy, misinformation sharing, and habits of verifying new information
  • Built a full-stack application using React, React Router v7, PostgreSQL, and Cytoscape.js
